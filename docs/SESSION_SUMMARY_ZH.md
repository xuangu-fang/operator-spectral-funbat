## 2. 核心结果

15 seeds，1% 观测，独立 forced-PDE 求解器场，所有 arm 共享场/mask/噪声/宿主/rank/优化器/step 预算：

| | held-out NRMSE |
|---|---|
| **PDE 形式 kernel（本文）** | **0.4431 ± 0.0539** |
| 通用字典（参数匹配） | 0.4818 ± 0.0615 |
| 最近邻 | 0.5699 |
| 离散 CP / Tucker 补全（EM） | ≥ 0.98（**不优于预测均值**） |
| kernel ridge（**oracle** 调长度尺度） | 0.4887 |
| 满观测 Tucker 天花板（所有 arm 共享） | 0.1791 |

配对 margin `+0.0387 ± 0.0256`（相对 8.0%），**15/15**，符号检验与 Wilcoxon 均 `p = 3.1e-05`。
margin 在 5% 观测时收缩到 0.003——这是先验应有的形状。

## 3. 方法（最终形态，比开始时简单得多）

1. 由算子符号得联合谱 $S_{\mathrm{op}}=\lvert\widehat{\mathcal L}\rvert^{-2}S_w$，**只用形式，系数取 nominal**；
2. 逐轴边缘化，得每个 mode 一个一维非负谱；
3. 该谱**就是**核：$k(x,x')=\sum_k s(k)\psi_k(x)\psi_k(x')$，对任意非负 $s$ 均 PSD。

**没有任何 kernel 参数需要学。** 消融证明在其上加非负低秩分离 + 学习 routing 不带来任何改变（0.4613 vs 0.4631，seed 间散布 0.025），因此字典、routing、support floor 已从方法中整体删除。

## 4. 三次 formulation 修订（都由数据推翻既有设定）

| 修订 | 触发 | 结果 |
|---|---|---|
| CP → **Tucker** 宿主，逐 mode 不同 rank | 真实二维场满观测 CP rank-10 只能到 0.32，而多线性秩仅 [2,11,11] | 二维场是团块不是外积；[2,11,11] 的 core 242 参数 vs 等秩 11 的 1331 |

## 6. 一个求解器 bug（值得记住的方法论）

块状强迫（`np.kron`）的谱是 sinc 型、带零点，而先验假设光滑高斯 $S_w$。于是**先验与数据的分歧落在强迫上而非算子上**，任何算子都不可能好、任何光滑先验都一样平庸。改为高斯滤波白噪声后，最不相似两 mode 的谱 cosine 从 0.39 升到 0.85。

**教训：比较先验之前，先验证数据的谱确实符合先验族假设的生成机制。**
