# 未来分支与待办（不属于当前论文主线）

当前论文的**唯一主指标是重构误差（held-out NRMSE）**。以下方向已经过评估，
判定为"体量足够单独成文"或"当前证据不足以支撑"，**不在本轮推进**。

---

## 1. 泄漏源定位（优先级最高的下一篇）

**为什么单独成篇而不是当作 application study。**
定位不是重构的一个副产品指标，它是一个**独立的推断问题**，做好需要：

- **一整套自己的 baseline 对比**：源反演/逆问题文献（伴随法、稀疏反卷积、
  压缩感知式源恢复）都有成熟方法，不与它们比就没有说服力；
- **贝叶斯框架**：实践者要的不是一个点估计，而是"源在这个区域内的概率"，
  以及"要不要派人去"。需要把后验不确定性完整传播到定位量上，
  而当前 host 的后验预测在稀疏区是**欠覆盖**的（1% 观测下 95% 区间实际覆盖 83.7%），
  这一条必须先修好，否则定位的置信区间不可信；
- **多源的对应关系**：多个源时预测峰与真源的匹配规则本身需要设计，
  且这个规则可被调参，必须预先声明。

**已完成的准备工作**（`experiments/run_leak_application.py`，已写好未跑完）：

- 每个 seed **随机重抽主源位置**，避免方法靠记住固定答案得分；
- 主源明确占优（宽度 0.13 vs 干扰源 0.05），否则时间平均场的 argmax
  未必对应被打分的那个源，指标会退化成"哪个 blob 碰巧赢了"；
- 指标是**房间宽度**为单位的距离，无需引用模型即可读懂；
- **报告指标下限**：即使在真实场上，峰值距真源也有 0.019–0.086
  （各向异性扩散会把峰推偏），没有这一行读者无法判断 0.05 算好算坏。

**一次早期观察（120 步欠训练，不作结论）**：三档全部在 0.40 房间宽度左右，
即从单面墙定位在当前重构质量下**很可能是做不到的**。这也说明它需要的是
新方法而不是新指标。

## 2. 物理感知的稀疏表征 → 归纳式任务（第二篇的另一个候选）

把算子谱下学到的 core 投影到隐空间，用于生成或跨场景泛化。
自然的第一个接口：**同一组算子基下，core 能否跨泄漏配置迁移**
（换源位置只重拟合 core，不动谱）。

**前置条件**：本轮发现这套先验**不会体面地失败**——几何超出它能力时
会输出比预测均值更差的结果（角块 1.0212、$y$ 墙 1.2652）。
一个连"何时该放弃"都不知道的表征，直接拿去做生成或跨场景泛化更危险。
**先补回退机制，再谈归纳式。**

## 3. 尚未解释的现象（记录在案，不投入）

- **$x$ 墙 / $y$ 墙的不对称**：同样 8% 覆盖，$x$ 墙追平 oracle，$y$ 墙输 44%。
  各向同性对照证明与各轴扩散系数无关。两面相邻墙（含同一个 $y$ 面）正常，
  所以不是"该面有毒"，而是"只沿 $y$ 外推"有毒。原因不明。
- **失败模式不体面**：全部实验中唯一超过 NRMSE 1.0 的臂始终是我们，
  baseline 最差只到 0.95。长尺度 Matérn 打不过时会收缩到均值并停下；
  我们的尺度被方程钉死，观测约束不住时继续外推。
  **部署前需要一个检测"正在超出观测约束范围"并转为收缩的回退机制。**

## 4. 已评估并降级的对照

- **固定长尺度通用核**：2D 上 $\ell=1.6$ 相对我们最差只差 0.0135，
  即在 2D 上物理相对"随手固定一个中庸常数"几乎没买到东西。
  已记录，不再投入调参。
- **逐维常数 oracle**：27 组合测试集搜索即可追平我们（−0.0018），
  说明我们相对共享常数的优势主要来自"各轴尺度不同"而非"谱形状对"。
  已记录，不再投入。
