## 2. 核心结果

15 seeds，独立 forced-PDE 求解器场，所有 arm 共享场/mask/噪声/宿主/rank/优化器/step 预算，**且各自使用对自己最优的 routing（两边都是 global）**：

| 观测率 | **PDE 形式 kernel（本文）** | 通用字典 | 最近邻 | paired wins |
|---|---:|---:|---:|---:|
| **1%** | **0.4217 ± 0.0470** | 0.4464 ± 0.0545 | 0.5699 | **13/15** |
| 2% | **0.3478** | 0.3581 | 0.4929 | **14/15** |
| 5% | **0.2969** | 0.2993 | 0.4073 | **13/15** |

1% 处配对 margin `+0.0247 ± 0.0235`（相对 5.5%），符号检验 $p=0.0037$，Wilcoxon $p=0.00058$。

其他 baseline（1%）：离散 CP / Tucker 补全 $\ge 0.98$（**不优于预测均值**）；kernel ridge（oracle 调长度尺度）0.4887；满观测 Tucker 天花板 0.1791。

> ⚠ **本轮后期纠正的一个错误**：更早的主表让两边都用 `per_mode_rank` routing，报出 15/15、相对 8.0%、$p=3\times10^{-5}$。消融显示该设置在 1% 下对两个 bank 都过拟合，且**对 generic 的伤害是对 operator 的两倍**（0.042 vs 0.023），因此**把效应高估了约 1.6 倍**。旧数字保留在 `headline_legacy_pmr_summary.json`。
>
> 教训：**"参数匹配"不等于"配置匹配"**。rank、预算、系数量都对齐了，但共用一个对 baseline 更不利的超参设置，依然是不公平比较。

## 3. 方法（最终形态，比开始时简单得多）

1. 由算子符号得联合谱 $S_{\mathrm{op}}=\lvert\widehat{\mathcal L}\rvert^{-2}S_w$，**只用形式，系数取 nominal**；
2. **非负低秩分离**成 $Q=4$ 个逐维原子 $s_{dq}$；
3. 学一个**全局混合权重**（4 个 logit，所有 mode 与 rank 共享），得每个 mode 的谱；该谱**就是**核：$k(x,x')=\sum_k s(k)\psi_k(x)\psi_k(x')$，对任意非负 $s$ 均 PSD。

**可学 kernel 参数只有 4 个。** per-mode/rank routing 在 1% 观测下过拟合（+0.023），不采用。

> ⚠ 会话中期曾错误地认为"单个边缘谱即可，分离和 routing 可全部删除"。那是在 per-mode/rank 下比较得出的，该设置拖累了两个 arm。同一协议下 global routing 的正确结果：分离 `0.4383` vs 单个边缘谱 `0.4631`，**分离确实有用**。

## 4. 三次 formulation 修订（都由数据推翻既有设定）

| 修订 | 触发 | 结果 |
|---|---|---|
| CP → **Tucker** 宿主，逐 mode 不同 rank | 真实二维场满观测 CP rank-10 只能到 0.32，而多线性秩仅 [2,11,11] | 二维场是团块不是外积；[2,11,11] 的 core 242 参数 vs 等秩 11 的 1331 |
| 周期 Fourier → **边界匹配本征基** | 初值数据时间维首末帧跳变是相邻步长的 5.6 倍 | 算子本征基由边界条件决定；无流边界下是余弦。同一次运行 NRMSE 1.30 → 1.08 |
| 模型自采样 → **独立数值求解器** | 此前全部正面结果的真值都采样自模型自身先验 | 场携带完整不可分联合谱，方法只见其边缘化近似 + 故意取错的系数 |

## 6. 一个求解器 bug（值得记住的方法论）

块状强迫（`np.kron`）的谱是 sinc 型、带零点，而先验假设光滑高斯 $S_w$。于是**先验与数据的分歧落在强迫上而非算子上**，任何算子都不可能好、任何光滑先验都一样平庸。改为高斯滤波白噪声后，最不相似两 mode 的谱 cosine 从 0.39 升到 0.85。

**教训：比较先验之前，先验证数据的谱确实符合先验族假设的生成机制。**
